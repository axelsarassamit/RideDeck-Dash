# Contributions

Read AGENTS.md before changing the project. Keep changes specific to RideDeck Dash and include a clear validation result. Run unit tests, debug assembly and lint before committing. Do not commit secrets or generated APKs.

Camera behavior needs physical testing. Record phone model, Android/HyperOS version, camera pair, encoder resolution/frame rate, stabilization modes, recording duration, screen state and observed issues. Never substitute an advertised mode for a completed recording test.
